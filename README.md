## Project Overview
This repository contains the progressive machine learning workshops developed for Team 4, focused on **Natural Language Processing (NLP)** and text classification. 

The project is built around a dataset of **42,656 Disneyland park reviews**, featuring ratings (1–5 stars), visit dates, reviewer locations, and park branches. Each workshop applies a core machine learning paradigm to this text domain.

---

## Workshops & Structure

| Folder | Focus Area | Key Implementation Goals |
| :--- | :--- | :--- |
| `Workshop #1/` | Supervised Learning | EDA, feature engineering, and baseline classification models (linear, trees, ensembles). |
| `Workshop #2/` | Deep Learning Basics | Sequence modeling with RNNs/LSTMs and transformers using TensorFlow/PyTorch. |
| `Workshop #3/` | Reinforcement Learning | Reward design, environment setup, and Q-learning or policy gradient methods. |
| `Workshop #4/` | Unsupervised Learning | Autoencoders & VAEs for dimensionality reduction and latent space analysis. |
| `Workshop #5/` | Generative Models (GANs) | Generator/discriminator architecture, training stability, and synthetic data generation. |
| `Workshop #6/` | Domain Adaptation | Advanced transfer learning, model interpretability (attention/saliency), and evaluation. |
